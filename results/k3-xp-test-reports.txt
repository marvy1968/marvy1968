# xp-test operations (VM instance-stockbot, /opt/xp-test) — PAPER ONLY

- Service: `xp-test.service` (one process, all 25 systems: the original 20 + 5 daily swing-book systems added 2026-10-02, trading from Mon 2026-10-05). Safety-net timer: `xp-test-flatten.timer` (15:57 ET weekdays,
  flattens only xp intraday positions still open).
- Daily schedule (ET): 08:45 prep (daily SIP bars, watchlists, earnings) · 09:20 + 09:31 gapper scans · 09:31-15:30 entries ·
  15:44 on-the-close decisions -> market-on-close orders · 15:55 intraday flatten · 16:05 MOC fills/EOD marks ·
  16:15 Telegram scorecard ([xp PAPER], chat ***, send-only) + reports; weekly summary on the last trading day of the week.
- Status: `cd /opt/xp-test && venv/bin/python -m xp.main --status` · `venv/bin/python -m xp.ctl list`
- Logs: `/opt/xp-test/logs/xp-test.log` (rotates daily) · `journalctl -u xp-test -f`
- Ledger (SQLite, every row tagged by system): `/opt/xp-test/state/xp_ledger.sqlite` (signals, orders, fills, positions, exits
  with P&L / R / slippage, daily, events). Reports: `/opt/xp-test/reports/` (scorecard_<day>.md/.csv, trades_all.csv, weekly_<day>.md).
- Stop ONE system: `venv/bin/python -m xp.ctl stop <system>` (flattens that system within ~10 s, no new entries);
  `pause <system>` = no new entries, positions managed; `resume <system>` undoes. `ALL` works for every system.
- Stop everything: `venv/bin/python -m xp.ctl stop ALL` (flattens), then `sudo systemctl disable --now xp-test xp-test-flatten.timer`.
  With the service down: `venv/bin/python -m xp.ctl flatten [--system S]` (direct, xp-owned quantities only).
- Disable a system permanently: set `enabled: false` under `systems:` in config/config.yaml, `sudo systemctl restart xp-test`.
