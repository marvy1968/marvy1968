*   **Realistic Target:** A highly optimized, fully automated retail strategy doing **15% to 30% annually** (+0.05% to +0.1% per day average) is phenomenal. Set your daily target to +0.1% and scale your capital, not your percentage expectations.

**Methodology Flaws Flattering Your Tests:**
1.  **Filter Overfitting:** Your filter list (*heat map, direction, Weinstein stage, multi-timeframe, reversal confirm, oversold gate, regime block, trend confirm*) is a massive red flag. This is the definition of "curve fitting." Every filter adds degrees of freedom. You haven't found a robust edge; you've carved out a perfect path through historical noise. Cut this down to *two* filters max (e.g., regime and trend).
2.  **Slippage Underestimation:** Mid/small caps have thin order books. If your backtest assumes you get filled at the bid/ask without modeling depth-of-book impact, your 1-minute test returns are heavily inflated.

#### Rank 2: Caching Indicator Frames (Medium Effort, High Gain)
If your grid search is only altering exit parameters (e.g., TP/SL), do not recalculate the VWAP/RSI/Bollinger Bands every iteration. Calculate the base indicators *once* for the whole universe, save to a dictionary, and pass it to the simulation.
*   **Gain:** Removes 30-50% of the overhead per grid point.

#### Rank 3: Successive Halving / Early Stopping (Low Effort, High Gain)
Don't let a 12-month backtest finish if it's clearly failing.
*   **Sketch:** Break your 12-month test into quarters. After Q1 (3 months), evaluate the Profit Factor. If PF < 0.8, `return "Failed Early"`. This frees up the VM queue exponentially faster by killing dead-end parameters.

#### Rank 4: Vectorization (High Effort, Massive Gain)
If you iterate row-by-row using `for index, row in df.iterrows()` or a `simulate_day` while loop, pandas is incredibly slow. You must use boolean masking. 
*   **Gain:** 100x to 1000x speedup. Minutes become milliseconds.
*   **Sketch:**
```python
# SLOW (Iterative)
for i in range(len(df)):
    if df['RSI'].iloc[i] < 30 and not in_position:
        buy()

# FAST (Vectorized)
# 1. Generate all signals instantly
df['signal'] = (df['RSI'] < 30).astype(int)

# 2. Shift to simulate buying on the *next* bar open
df['position'] = df['signal'].shift(1)

# 3. Calculate returns instantly
df['strategy_returns'] = df['position'] * df['pct_change']
```
*(Note: Complex path-dependent exits like trailing stops are hard to vectorize. For those, use Numba).*

#### Rank 5: Numba (Medium Effort, Medium Gain)
If you *must* use a loop for path-dependent logic (like your structure stops or the 10-minute underwater rule), wrap the loop in Numba.
*   **Rule:** Pass underlying numpy arrays to Numba, not Pandas DataFrames.
*   **Sketch:**
```python
from numba import njit
import numpy as np

@njit
def fast_simulate(prices, signals, stop_loss):
    in_pos = False
    pnl = 0.0
    for i in range(len(prices)):
        if not in_pos and signals[i] == 1:
            entry = prices[i]
            in_pos = True
        elif in_pos and prices[i] < entry * (1 - stop_loss):
            pnl += prices[i] - entry
            in_pos = False
    return pnl

# Call passing numpy arrays
fast_simulate(df['close'].values, df['signal'].values, 0.01)
```
