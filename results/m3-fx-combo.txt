# Expert combos (PAPER) with a hard 1% stop and a 1% take-profit (built Fri 2026-10-09)

Marvin asked for complementary experts combined, with "a hard 1% virtual stop on each trade and a TP on each".
There are two combos, kept separate from the existing bots:

| combo | where | members | broker |
|---|---|---|---|
| **xp-combo** (stocks) | `/opt/xp-combo`, `xp-combo.service` | crabel-orb, velez-mr, velez-rbi, qull-bo | **Alpaca PAPER**: the same paper account as xp-test, orders prefixed `xc-` |
| **fx-combo** (FX) | `/opt/fx-combo`, `fx-combo.timer` (every 2 min) | faith-turtle, lien-zeros, tharp-random | **SHADOW**: live OANDA practice prices, virtual book, never writes to OANDA |

Live money is not enabled anywhere. Alpaca is limited to the paper URL by `safety.assert_paper`. The FX shadow
overrides every OANDA write method, and its `_write` raises an error.

## Why these members (xp-test ledger + OANDA closed trades, Oct 2 to Oct 9)
Daily realized P&L, plus today's open marks, from the xp-test ledger:
- **crabel-orb** (ORB breakout, intraday): -243 / +56 / +242 / +258 (open, Oct 9). This is the only xp system with
  positive realized P&L.
- **velez-mr** (mean reversion, intraday): +29 on Oct 2, the day crabel lost 243. Its correlation with crabel is negative.
- **velez-rbi** (intraday): +11 on Oct 9, while velez-mr was -30. Correlation is about -0.5 with velez-mr and +0.2 with crabel.
- **qull-bo** (Kullamagi swing breakout): it holds for days, so its P&L comes on different days from the intraday
  systems. Realized -17, but about +590 open, the best of all systems.
- FX: **faith-turtle** (daily trend breakout), **lien-zeros** (round-figure mean reversion, the only FX winner at +295)
  and **tharp-random** (random entry with a volatility trail, +178 open). These have different edge types, and Tharp
  trades crosses that the other two never touch.
- Caveat: there are only 4 stock sessions and 11 closed FX trades. The correlations are directional hints, not
  statistics. Re-check after 3 to 4 weeks.

## Hard stop / take-profit rules (both combos)
- **Stop:** the tighter of the expert's book stop and entry ∓ **1.0%**, measured from the actual fill.
- **Take-profit:** the nearer of the book target and entry ± **1.0%**. This gives 1:1 R:R when the book stop is wider
  than 1%, and better than 1:1 when the book stop is tighter (for example lien-zeros: 20-pip stop, 40-pip target).
  Book partials beyond the take-profit are dropped.
- **Sizing:** uses the effective stop, so risk stays at 0.25% of equity per trade, capped at 10% notional.
- Trailing stops still move, but only tighter. The stop is never loosened past the hard level.
- **Enforcement:**
  - xp-combo places the stop and the target OCO at Alpaca, and also runs `Engine.enforce_hard()` on every price
    update (about every 10 s). If the last price is through the stop or the take-profit, it cancels the broker orders
    and exits at market. A failed exit is retried every 15 s, then every 60 s.
  - fx-combo replays every M1 bar since the last run. A stop or target touched between runs is filled at its level,
    or at the bar open if price gapped through it. If one bar touches both, the stop is assumed to fill first.
- Settings: `hard_exit:` in `/opt/xp-combo/config/config.yaml`, and env `FXC_HARD_STOP_PCT` / `FXC_HARD_TP_PCT` for fx-combo.

## Coexistence
- xp-combo shares xp-test's Alpaca paper account. Each bot treats the other's symbols as "busy with another bot":
  xp-test skips anything with non-`xp-` orders or shares it does not own, and xp-combo does the same for non-`xc-`.
  The two never trade the same symbol at once. Because crabel-orb and velez-* run in both, the first to fire on a
  symbol takes it.
- xp-test and fx-experts were not modified or restarted.
- To trade the FX combo with real practice orders, create a second OANDA practice sub-account and give it its own
  token/account. The current token sees only the account fx-experts uses, which is FIFO and no-hedge.

===== ./fxexp/backtest.py
"""Event backtester on real OANDA H4 candles (mid) with an intrabar path model.

Path model: bullish bar O->L->H->C, bearish bar O->H->L->C.  Orders trigger on the correct side of
the quote (long entry/short stop on ask, short entry/long stop on bid) using a typical spread; stop
fills get extra slippage; fills at the 17:00 NY open use a widened spread.  Financing is charged
per rollover held (x3 for the Wednesday rollover).  No parameters are fitted to the data."""
import math
from dataclasses import dataclass, asdict
import pandas as pd
from .data import load_csv, to_daily, trade_date
from .instruments import pip, spread, ROLL_MULT, SLIP_PIPS, FIN_PIPS_PER_NIGHT
from .strategies.base import Position

@dataclass
class Trade:
    system: str; pair: str; side: int; entry_time: str; exit_time: str
    entry: float; exit: float; sl0: float; risk: float; r: float; reason: str; nights: int; meta: str

def nights_between(dates, i0, i1):
    n = 0
    for k in range(i0 + 1, i1 + 1):
        n += 3 if dates[k].weekday() == 3 else 1
    return n

class Sim:
    def __init__(self, strat, pair, h4, daily):
        self.s, self.pair, self.daily = strat, pair, daily
        self.dates = list(daily.index)
        h4 = h4.copy(); h4["date"] = pd.to_datetime(trade_date(h4["time"]))
        self.bars = {d: g for d, g in h4.groupby("date")}
        self.sp = spread(pair); self.slip = SLIP_PIPS * pip(pair); self.t = pip(pair)
        self.state, self.pos, self.pending, self.trades = {}, None, [], []

    # ---- helpers -------------------------------------------------------
    def _open_pos(self, o, fill, when, di, day_lo, day_hi, day_open):
        side = o.side
        if o.sl is not None: sl = o.sl
        elif o.sl_from_open is not None: sl = day_open + o.sl_from_open
        elif o.sl_dist is not None: sl = fill - side * o.sl_dist
        elif o.sl_daylow: sl = (day_lo - self.sp / 2 - self.t) if side == 1 else (day_hi + self.sp / 2 + self.t)
        else: raise ValueError("order without stop")
        if (fill - sl) * side <= 0: return None      # stop already through: skip
        tp = o.tp if o.tp is not None else (fill + side * o.tp_dist if o.tp_dist else None)
        self.pos = Position(side, fill, sl, tp, abs(fill - sl), di, when, o.close_eod, dict(o.meta, sl0=sl))
        self.pending = []                              # OCO: one trade per pair per system
        return self.pos

    def _close(self, px, when, di, reason):
        p = self.pos
        nts = nights_between(self.dates, p.entry_di, di)
        fin = nts * FIN_PIPS_PER_NIGHT * self.t
        r = (p.side * (px - p.entry) - fin) / p.risk
        self.trades.append(Trade(self.s.sid, self.pair, p.side, str(p.entry_time), str(when), p.entry, px,
                                 p.meta["sl0"], p.risk, r, reason, nts,
                                 ";".join(f"{k}={v:.5g}" if isinstance(v, float) else f"{k}={v}" for k, v in p.meta.items() if k not in ("sl0",))))
        self.pos = None

    def _triggers(self, day_open):
        """Return list of (mid_level, direction, kind, obj). direction +1 fires on up-moves."""
        out, h = [], self.sp / 2
        p = self.pos
        if p is not None:
            out.append((p.sl + h if p.side == 1 else p.sl - h, -p.side, "sl", None))
            if p.tp is not None:
                out.append((p.tp + h if p.side == 1 else p.tp - h, p.side, "tp", None))
            return out
        for o in self.pending:
            if o.kind != "stop": continue
            if o.arm is not None and not o.armed:
                out.append((o.arm, -o.side, "arm", o))
                continue
            lvl = o.price if o.price is not None else day_open + o.from_open
            out.append((lvl - h if o.side == 1 else lvl + h, o.side, "entry", o))
        return out

    def _walk_bar(self, bar, di, day_open, ext):
        o_, h_, l_, c_ = bar.open, bar.high, bar.low, bar.close
        pts = [o_, l_, h_, c_] if c_ >= o_ else [o_, h_, l_, c_]
        when = bar.time; a = pts[0]; first = True
        for b in pts[1:] + [None]:
            # gap check at bar open (first point only) then segment a->b
            for _guard in range(20):
                trig = self._triggers(day_open)
                hit = None
                if first:
                    for lvl, d, kind, obj in trig:
                        if (d == 1 and a >= lvl) or (d == -1 and a <= lvl): hit = (lvl, d, kind, obj, a); break
                if hit is None and b is not None:
                    cands = [(lvl, d, kind, obj) for lvl, d, kind, obj in trig
                             if (d == 1 and b > a and a <= lvl <= b) or (d == -1 and b < a and b <= lvl <= a)]
                    if cands:
                        lvl, d, kind, obj = min(cands, key=lambda x: abs(x[0] - a)); hit = (lvl, d, kind, obj, lvl)
                if hit is None: break
                lvl, d, kind, obj, px = hit
                ext[0] = min(ext[0], px); ext[1] = max(ext[1], px)
                h = self.sp / 2
                if kind == "arm":
                    obj.armed = True
                elif kind == "entry":
                    fill = (px + h + self.slip) if obj.side == 1 else (px - h - self.slip)
                    self._open_pos(obj, fill, when, di, ext[0], ext[1], day_open)
                elif kind == "sl":
                    p = self.pos; fill = (px - h - self.slip) if p.side == 1 else (px + h + self.slip)
                    k = di - p.entry_di + 1; old = p
                    self._close(fill, when, di, "stop")
                    ro = self.s.after_stop(old, k, self.pair, self.state)
                    if ro is not None: ro.meta["_exp"] = di + ro.expires_days; self.pending = [ro]
                elif kind == "tp":
                    p = self.pos; fill = (px - h) if p.side == 1 else (px + h)
                    self._close(fill, when, di, "target")
                a = px
            first = False
            if b is None: break
            ext[0] = min(ext[0], b); ext[1] = max(ext[1], b)
            a = b

    def run(self, start=None, end=None):
        d = self.daily
        for di in range(self.s.warmup, len(self.dates)):
            date = self.dates[di]
            if (start is not None and date < start) or (end is not None and date > end): continue
            bars = self.bars.get(date)
            if bars is None or bars.empty: continue
            self.pending = [o for o in self.pending if o.meta.get("_exp", -1) >= di]
            if self.pos is None:
                for o in self.s.plan(d.iloc[:di], self.pair, self.state):
                    o.meta["_exp"] = di + o.expires_days; self.pending.append(o)
            day_open = float(bars.iloc[0].open); ext = [day_open, day_open]
            # market orders fill at the day's first price with a widened rollover spread
            for o in [o for o in self.pending if o.kind == "market"]:
                if self.pos is None:
                    h = self.sp * ROLL_MULT / 2
                    fill = day_open + h + self.slip if o.side == 1 else day_open - h - self.slip
                    self._open_pos(o, fill, bars.iloc[0].time, di, day_open, day_open, day_open)
            self.pending = [o for o in self.pending if o.kind != "market"]
            for bar in bars.itertuples():
                self._walk_bar(bar, di, day_open, ext)
            last = bars.iloc[-1]; h = self.sp / 2
            if self.pos is not None:
                p = self.pos
                if p.close_eod:
                    self._close(last.close - h - self.slip if p.side == 1 else last.close + h + self.slip, last.time, di, "eod")
                else:
                    m = self.s.manage(p, d.iloc[:di + 1], self.pair, self.state)
                    if m.close:
                        self._close(last.close - h - self.slip if p.side == 1 else last.close + h + self.slip, last.time, di, m.reason or "exit")
                    elif m.new_sl is not None:
                        p.sl = m.new_sl
        return self.trades

def stats(rs):
    rs = list(rs); n = len(rs)
    if n == 0: return dict(trades=0, win=0.0, pf=float("nan"), net_r=0.0, avg_r=0.0, maxdd_r=0.0)
    w = [r for r in rs if r > 0]; l = [r for r in rs if r <= 0]
    pf = sum(w) / -sum(l) if l and sum(l) < 0 else float("inf")
    eq = peak = dd = 0.0
    for r in rs:
        eq += r; peak = max(peak, eq); dd = max(dd, peak - eq)
    return dict(trades=n, win=100.0 * len(w) / n, pf=pf, net_r=sum(rs), avg_r=sum(rs) / n, maxdd_r=dd)

===== ./fxexp/data.py
"""Candle loading and NY-17:00 daily aggregation (OANDA dailyAlignment=17, America/New_York)."""
import pandas as pd

NY = "America/New_York"

def load_csv(path):
    df = pd.read_csv(path)
    tcol = "timestamp" if "timestamp" in df.columns else df.columns[0]
    df["time"] = pd.to_datetime(df[tcol], utc=True)
    df = df[["time", "open", "high", "low", "close"]].sort_values("time").drop_duplicates("time")
    return df.reset_index(drop=True)

def trade_date(ts_utc):
    """FX trading day: a bar starting at/after 17:00 NY belongs to the next calendar date."""
    ny = ts_utc.dt.tz_convert(NY) if hasattr(ts_utc, "dt") else ts_utc.tz_convert(NY)
    return (ny + pd.Timedelta(hours=7)).dt.date if hasattr(ny, "dt") else (ny + pd.Timedelta(hours=7)).date()

def to_daily(intraday):
    df = intraday.copy(); df["date"] = trade_date(df["time"])
    g = df.groupby("date", sort=True)
    d = pd.DataFrame({"open": g["open"].first(), "high": g["high"].max(), "low": g["low"].min(),
                      "close": g["close"].last(), "nbars": g.size()})
    d = d[d["nbars"] >= 2]  # drop stray single-bar holiday fragments
    d.index = pd.to_datetime(d.index)
    return d

===== ./fxexp/duka.py
"""Convert Dukascopy CSV (ms epoch, OHLC, volume) to mid candles. If only one side is available,
shift it by half the typical OANDA spread."""
import os, glob
import pandas as pd
from .instruments import spread

def load_side(path):
    df = pd.read_csv(path)
    if df.empty: return None
    df["time"] = pd.to_datetime(df["timestamp"], unit="ms", utc=True)
    if "volume" in df.columns: df = df[df["volume"] > 0]
    return df.set_index("time")[["open", "high", "low", "close"]]

def build_mid(pair, src_dirs, tf="h1"):
    code = pair.replace("_", "").lower(); sides = {}
    for side in ("bid", "ask"):
        parts = []
        for d in src_dirs:
            for f in sorted(glob.glob(os.path.join(d, f"{code}-{tf}-{side}-*.csv"))):
                try: x = load_side(f)
                except Exception: x = None
                if x is not None and len(x): parts.append(x)
        if parts:
            x = pd.concat(parts); sides[side] = x[~x.index.duplicated(keep="last")].sort_index()
    b, a = sides.get("bid"), sides.get("ask"); h = spread(pair) / 2
    if b is not None and a is not None:
        idx = b.index.intersection(a.index); cover = len(idx) / max(len(b), len(a))
        if cover > 0.97: m = (b.loc[idx] + a.loc[idx]) / 2; return m, "bid/ask mid"
        if cover > 0.5:   # hybrid: true mid where both sides exist, one side +- half spread elsewhere
            m = (b.loc[idx] + a.loc[idx]) / 2
            rest_a = (a.drop(idx, errors="ignore") - h); rest_b = (b.drop(idx, errors="ignore") + h)
            out = pd.concat([m, rest_a, rest_b]); out = out[~out.index.duplicated()].sort_index()
            return out, f"hybrid mid ({cover:.0%} true mid)"
    best = max([x for x in (b, a) if x is not None], key=len)
    if best is b: return best + h, "bid+half spread"
    return best - h, "ask-half spread"

"""Pure-numpy/pandas indicators on daily bars (columns open/high/low/close)."""
import numpy as np
import pandas as pd

def true_range(df):
    pc = df["close"].shift(1)
    return pd.concat([df["high"] - df["low"], (df["high"] - pc).abs(), (df["low"] - pc).abs()], axis=1).max(axis=1)

def wilder(series, n):
    """Wilder smoothing seeded with the simple mean of the first n values."""
    s = series.to_numpy(dtype=float); out = np.full(len(s), np.nan)
    vals = np.where(np.isnan(s), np.nan, s)
    start = np.argmax(~np.isnan(vals)) if (~np.isnan(vals)).any() else len(s)
    if start + n > len(s): return pd.Series(out, index=series.index)
    out[start + n - 1] = np.nanmean(vals[start:start + n])
    for i in range(start + n, len(s)):
        out[i] = (out[i - 1] * (n - 1) + vals[i]) / n
    return pd.Series(out, index=series.index)

def turtle_n(df, n=20):
    """Turtle N: N = (19*PDN + TR)/20 (Original Turtle Rules), seeded with a 20-day mean TR."""
    return wilder(true_range(df), n)

def adx(df, n=14):
    up = df["high"].diff(); dn = -df["low"].diff()
    pdm = pd.Series(np.where((up > dn) & (up > 0), up, 0.0), index=df.index)
    mdm = pd.Series(np.where((dn > up) & (dn > 0), dn, 0.0), index=df.index)
    tr = true_range(df); tr.iloc[0] = np.nan; pdm.iloc[0] = np.nan; mdm.iloc[0] = np.nan
    atr = wilder(tr, n); pdi = 100 * wilder(pdm, n) / atr; mdi = 100 * wilder(mdm, n) / atr
    dx = 100 * (pdi - mdi).abs() / (pdi + mdi)
    return wilder(dx, n)

def bollinger(close, n=20, k=2.0):
    mid = close.rolling(n).mean(); sd = close.rolling(n).std(ddof=0)  # Bollinger uses population sd
    return mid - k * sd, mid, mid + k * sd

def bandwidth(close, n=20, k=2.0):
    lo, mid, up = bollinger(close, n, k)
    return (up - lo) / mid

def parabolic_step(sar, ep, af, long, high, low, prev_high, prev_low, step=0.02, maxaf=0.20):
    """One Wilder Parabolic SAR update for the next bar given today's bar. Returns (sar, ep, af)."""
    new = sar + af * (ep - sar)
    if long:
        new = min(new, low, prev_low)
        if high > ep: ep, af = high, min(af + step, maxaf)
    else:
        new = max(new, high, prev_high)
        if low < ep: ep, af = low, min(af + step, maxaf)
    return new, ep, af

def atr(df, n=14):
    """Wilder ATR."""
    return wilder(true_range(df), n)

def ema(series, n):
    return series.ewm(span=n, adjust=False).mean()

def tharp_vol(df, n=10):
    """Tharp/Basso volatility: 10-day exponential moving average of the true range."""
    tr = true_range(df); tr.iloc[0] = (df["high"] - df["low"]).iloc[0]
    return ema(tr, n)

PAIRS = ["EUR_USD", "GBP_USD", "USD_JPY", "AUD_USD", "USD_CAD", "USD_CHF", "NZD_USD", "EUR_JPY", "GBP_JPY"]

TYPICAL_SPREAD_PIPS = {"EUR_GBP": 1.6, "EUR_CHF": 2.2, "AUD_JPY": 2.2, "CAD_JPY": 2.6, "AUD_NZD": 3.0, "EUR_AUD": 2.8,
                       "EUR_USD": 1.4, "GBP_USD": 2.0, "USD_JPY": 1.4, "AUD_USD": 1.4, "USD_CAD": 2.2,
                       "USD_CHF": 1.8, "NZD_USD": 2.0, "EUR_JPY": 2.0, "GBP_JPY": 3.0}
ROLL_MULT = 2.0          # spread multiplier for fills right at the 17:00 NY daily open
SLIP_PIPS = 0.3          # extra slippage on stop-type fills (entry stops, stop losses, market)
FIN_PIPS_PER_NIGHT = 0.3 # rough net financing cost per 17:00 NY rollover held (x3 on Wednesday)
MAX_SPREAD_MULT = 2.5    # live: do not place/fire orders if spread > this x typical

def pip(pair: str) -> float:
    return 0.01 if pair.endswith("_JPY") else 0.0001

def precision(pair: str) -> int:
    return 3 if pair.endswith("_JPY") else 5

def spread(pair: str) -> float:
    """Typical spread in price units."""
    return TYPICAL_SPREAD_PIPS[pair] * pip(pair)

def rnd(pair: str, px: float) -> float:
    return round(px, precision(pair))

===== ./fxexp/live.py
"""Live/paper runner for the five systems on OANDA v20 (practice by default).

One-shot and idempotent: a systemd timer runs it every 5 minutes.  Each run
  * at the first run after 17:15 NY of a new trading day: end-of-day management of open trades
    (trail/time exits) using the just-closed daily candle, then plans today's entry orders;
  * intraday: arms conditional orders from today's 5-minute highs/lows, places broker-side stop
    entries with stopLossOnFill/takeProfitOnFill (GTD = 17:00 NY), keeps Turtle Soup's
    'one tick under today's low' stop current before the fill, cancels OCO siblings after a fill,
    queues Turtle Soup re-entries, and flattens day trades (Crabel) at 16:50 NY.
Every stop and target lives at OANDA, so a crash or VM reboot never leaves a trade unprotected.
"""
import argparse, json, os, sys, time, traceback, dataclasses
from datetime import datetime, timedelta, timezone, date
from zoneinfo import ZoneInfo
import pandas as pd

from .strategies import BY_SID
from .strategies.base import Order, Position
from .instruments import PAIRS, ALL_PAIRS, pip, precision, rnd, spread as typ_spread, MAX_SPREAD_MULT
from .sizing import units_for_risk
from .oanda import Oanda, OandaError

NY = ZoneInfo("America/New_York")
TAG = "fxexp"

# ---------------------------------------------------------------- time helpers
def trading_day(ts):
    """FX trading date for an aware datetime: after 17:00 NY belongs to the next date."""
    return (ts.astimezone(NY) + timedelta(hours=7)).date()

def day_bounds(td):
    start = datetime(td.year, td.month, td.day, 17, 0, tzinfo=NY) - timedelta(days=1)
    end = datetime(td.year, td.month, td.day, 17, 0, tzinfo=NY)
    return start, end

def market_open(now):
    n = now.astimezone(NY); wd = n.weekday()
    if wd == 5: return False
    if wd == 4 and n.hour >= 17: return False
    if wd == 6 and n.hour < 17: return False
    return True

def in_rollover(now):
    n = now.astimezone(NY); m = n.hour * 60 + n.minute
    return 16 * 60 + 55 <= m < 17 * 60 + 15

def fmt_px(pair, x): return f"{rnd(pair, x):.{precision(pair)}f}"

# ---------------------------------------------------------------- order math (pure)
def entry_levels(o, pair, day_open, day_low, day_high, spr):
    """Return (entry_level, stop_price, stop_distance, tp_price) for a stop-entry order."""
    t = pip(pair)
    level = o.price if o.price is not None else day_open + o.from_open
    if o.sl is not None: sl = o.sl
    elif o.sl_from_open is not None: sl = day_open + o.sl_from_open
    elif o.sl_dist is not None: sl = level - o.side * o.sl_dist
    elif o.sl_daylow: sl = (day_low - spr / 2 - t) if o.side == 1 else (day_high + spr / 2 + t)
    else: raise ValueError("order without a stop")
    tp = o.tp if o.tp is not None else (level + o.side * o.tp_dist if o.tp_dist else None)
    return level, sl, (o.sl_dist if o.sl_dist is not None else None), tp

def is_armed(o, day_low, day_high):
    if o.arm is None: return True
    return day_low <= o.arm if o.side == 1 else day_high >= o.arm

def order_body(pair, o, units, level, sl, sl_dist, tp, gtd, cid, sid, spr):
    body = {"type": {"stop": "STOP", "limit": "LIMIT"}.get(o.kind, "MARKET"), "instrument": pair,
            "units": str(units * o.side), "positionFill": "OPEN_ONLY",
            "clientExtensions": {"id": cid, "tag": TAG, "comment": sid},
            "tradeClientExtensions": {"id": "t-" + cid, "tag": TAG, "comment": sid}}
    if o.kind == "stop":
        body.update(price=fmt_px(pair, level), timeInForce="GTD", gtdTime=gtd.astimezone(timezone.utc).strftime("%Y-%m-%dT%H:%M:%S.000000000Z"),
                    priceBound=fmt_px(pair, level + o.side * 3 * spr))
    elif o.kind == "limit":
        body.update(price=fmt_px(pair, level), timeInForce="GTD", gtdTime=gtd.astimezone(timezone.utc).strftime("%Y-%m-%dT%H:%M:%S.000000000Z"))
    else:
        body.update(timeInForce="FOK")
    if sl_dist is not None:
        body["stopLossOnFill"] = {"distance": f"{sl_dist:.{precision(pair)}f}", "timeInForce": "GTC"}
    else:
        body["stopLossOnFill"] = {"price": fmt_px(pair, sl), "timeInForce": "GTC"}
    if tp is not None:
        body["takeProfitOnFill"] = {"price": fmt_px(pair, tp), "timeInForce": "GTC"}
    return body

def o2d(o): return dataclasses.asdict(o)
def d2o(d): return Order(**{k: v for k, v in d.items() if k in {f.name for f in dataclasses.fields(Order)}})

# ---------------------------------------------------------------- runner
class Runner:
    def __init__(self, cfg, clients, state_path, now=None, log=print):
        self.cfg, self.clients, self.state_path = cfg, clients, state_path
        self.now = now or datetime.now(timezone.utc); self.log = log
        self.state = json.load(open(state_path)) if os.path.exists(state_path) else {}
        self._daily, self._intra, self._prices, self._bars = {}, {}, {}, {}

    def save(self):
        tmp = self.state_path + ".tmp"; json.dump(self.state, open(tmp, "w"), indent=1, default=str); os.replace(tmp, self.state_path)

    # data (shared across systems in one run; reads use the first client)
    def daily(self, cli, pair, td):
        if pair not in self._daily:
            df = cli.candles(pair, "D", count=400)
            df = df[df["complete"]].copy()
            df["date"] = pd.to_datetime([trading_day(t.to_pydatetime()) for t in df["time"]])
            self._daily[pair] = df.set_index("date")[["open", "high", "low", "close"]]
        d = self._daily[pair]
        return d[d.index < pd.Timestamp(td)]

    def intraday(self, cli, pair, td):
        if pair not in self._intra:
            start, _ = day_bounds(td)
            df = cli.candles(pair, "M5", frm=start.astimezone(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ"))
            if df.empty: self._intra[pair] = None
            else: self._intra[pair] = (float(df["open"].iloc[0]), float(df["low"].min()), float(df["high"].max()))
        return self._intra[pair]

    def bars(self, cli, pair, td):
        """Completed M5 bars of the last ~5 calendar days (intraday systems), with trading date 'td'."""
        if pair not in self._bars:
            # most recent ~1700 M5 candles (~6 trading days). NB: 'from' without 'count' returns only 500.
            df = cli.candles(pair, "M5", count=1700)
            if not df.empty:
                df = df[df["complete"]].copy()
                if "volume" not in df: df["volume"] = 1
                df["td"] = [trading_day(t.to_pydatetime()) for t in df["time"]]
                df = df.reset_index(drop=True)
            self._bars[pair] = df
        return self._bars[pair]

    def pairs_for(self, sid, strat):
        return self.cfg.get("system_pairs", {}).get(sid) or strat.pairs or self.cfg["pairs"]

    def prices(self, cli):
        if not self._prices:
            names = list(dict.fromkeys(list(PAIRS) + [p for sid in self.cfg["systems"] for p in self.pairs_for(sid, BY_SID[sid]())]))
            self._prices = cli.pricing([p for p in names if p in ALL_PAIRS])
        return self._prices

    def run(self):
        if not market_open(self.now):
            self.log("market closed; nothing to do"); return
        td = trading_day(self.now)
        for sid in self.cfg["systems"]:
            cli = self.clients[sid]; strat = BY_SID[sid]()
            try:
                self.run_system(sid, strat, cli, td)
            except Exception as e:
                self.log(f"[{sid}] ERROR {e}\n{traceback.format_exc()}")
        self.save()

    def run_system(self, sid, strat, cli, td):
        st = self.state.setdefault(sid, {})
        all_trades = cli.open_trades()
        trades = [t for t in all_trades if t.get("clientExtensions", {}).get("comment") == sid]
        # US accounts: no hedging + FIFO. Never open a pair another system/bot already holds in this account.
        busy = {t["instrument"] for t in all_trades if t.get("clientExtensions", {}).get("comment") != sid}
        pend = [o for o in cli.pending_orders() if o.get("clientExtensions", {}).get("comment") == sid]
        summ = cli.summary(); nav = float(summ["NAV"]); prices = self.prices(cli)
        # account-level safety: with 11 systems sharing one account, stop adding exposure when
        # margin in use exceeds max_margin_used (default 50%) of NAV. Existing trades keep their stops.
        self._margin_full = float(summ.get("marginUsed", 0) or 0) > self.cfg.get("max_margin_used", 0.5) * nav
        mids = {k: (b + a) / 2 for k, (b, a, _) in prices.items()}
        n = self.now.astimezone(NY)
        for pair in self.pairs_for(sid, strat):
            ps = st.setdefault(pair, {"day": None, "orders": [], "trades": {}, "sstate": {}})
            ptrades = [t for t in trades if t["instrument"] == pair]
            ppend = [o for o in pend if o["instrument"] == pair]
            self.sync_closed(sid, strat, cli, pair, ps, ptrades, td)
            for t in ptrades: self.register(ps, t, td)
            # --- once per trading day, after the rollover settles
            if ps["day"] != str(td) and not in_rollover(self.now):
                hist = self.daily(cli, pair, td)
                for t in ptrades: self.eod_manage(sid, strat, cli, pair, ps, t, hist)
                for o in ppend: cli.cancel_order(o["id"]); self.log(f"[{sid}] {pair} cancel stale order {o['id']}")
                ppend = []
                carry = [r for r in ps["orders"] if r["exp"] >= str(td) and r["status"] in ("planned", "armed", "placed")]
                for r in carry: r["status"] = "planned"
                ps["orders"] = carry
                if not ptrades and not self.cfg.get("no_new_entries"):
                    for i, o in enumerate(strat.plan(hist, pair, ps["sstate"])):
                        ps["orders"].append({"o": o2d(o), "status": "planned", "cid": f"{sid[:6]}-{pair}-{td:%Y%m%d}-{i}", "exp": str(td + timedelta(days=o.expires_days))})
                ps["day"] = str(td)
                if ps["orders"]: self.log(f"[{sid}] {pair} planned {len(ps['orders'])} order(s) for {td}")
            # --- day trades: flat before the close
            if (n.hour, n.minute) >= (16, 50) and n.hour < 17:
                for t in ptrades:
                    if ps["trades"].get(t["id"], {}).get("close_eod"):
                        cli.close_trade(t["id"]); self.log(f"[{sid}] {pair} close day trade {t['id']} (eod)")
                for o in ppend: cli.cancel_order(o["id"])
                continue
            if in_rollover(self.now): continue
            if pair in busy and not ptrades:
                for o in ppend: cli.cancel_order(o["id"]); self.log(f"[{sid}] {pair} cancel {o['id']}: pair held by another system/bot")
                for r in ps["orders"]:
                    if r["status"] == "placed": r["status"] = "armed"
                continue
            if strat.intraday and not ptrades and not self.cfg.get("no_new_entries"):
                self.intraday_signal(sid, strat, cli, pair, ps, td)
            self.intraday_orders(sid, cli, pair, ps, ptrades, ppend, td, nav, mids, prices)

    def sync_closed(self, sid, strat, cli, pair, ps, ptrades, td):
        """Detect trades that closed since last run (Turtle Soup re-entry rule)."""
        open_ids = {t["id"] for t in ptrades}
        for tid, meta in list(ps["trades"].items()):
            if tid in open_ids: continue
            ps["trades"].pop(tid)
            try: tr = cli.trade(tid)
            except OandaError: continue
            stopped = tr.get("stopLossOrder", {}).get("state") == "FILLED"
            day_k = len(pd.bdate_range(meta["entry_day"], str(td)))  # trading days incl. entry day
            if stopped:
                pos = Position(meta["side"], float(tr["price"]), 0, None, 0, 0, None, meta=meta.get("meta", {}))
                ro = strat.after_stop(pos, day_k, pair, ps["sstate"])
                if ro is not None:
                    ps["orders"] = [{"o": o2d(ro), "status": "planned", "cid": f"{sid[:6]}-{pair}-{td:%Y%m%d}-r",
                                     "exp": str(td + timedelta(days=ro.expires_days))}]
                    self.log(f"[{sid}] {pair} queued re-entry after stop on day {day_k}")

    def register(self, ps, t, td):
        """Remember side/entry day/strategy meta for a trade opened by one of our orders."""
        if t["id"] in ps["trades"]: return
        cid = t.get("clientExtensions", {}).get("id", "")[2:]
        rec = next((r for r in ps["orders"] if r["cid"] == cid), None)
        o = d2o(rec["o"]) if rec else None
        if rec: rec["status"] = "filled"
        ps["trades"][t["id"]] = {"side": 1 if float(t["currentUnits"]) > 0 else -1,
                                 "entry_day": str(trading_day(pd.Timestamp(t["openTime"]).to_pydatetime())),
                                 "close_eod": bool(o and o.close_eod), "meta": dict(o.meta) if o else {}}

    def eod_manage(self, sid, strat, cli, pair, ps, t, hist):
        meta = ps["trades"][t["id"]]
        side = meta["side"]; sl = float(t["stopLossOrder"]["price"]) if t.get("stopLossOrder") else None
        ed = pd.Timestamp(meta["entry_day"])
        entry_di = int((hist.index < ed).sum())
        pos = Position(side, float(t["price"]), sl, None, 0.0, entry_di, t["openTime"], meta=meta["meta"])
        m = strat.manage(pos, hist, pair, ps["sstate"])
        if m.close:
            cli.close_trade(t["id"]); self.log(f"[{sid}] {pair} close {t['id']} ({m.reason})")
        elif m.new_sl is not None and sl is not None and (m.new_sl - sl) * side > pip(pair) * 0.1:
            cli.set_stop(t["id"], fmt_px(pair, m.new_sl)); self.log(f"[{sid}] {pair} trail stop {t['id']} {fmt_px(pair, sl)} -> {fmt_px(pair, m.new_sl)}")

    def intraday_signal(self, sid, strat, cli, pair, ps, td):
        """Intraday systems: ask the strategy for a new entry when it has nothing live on this pair."""
        if any(r["status"] in ("planned", "armed", "placed", "sent") for r in ps["orders"]): return
        sig = ps.setdefault("sig", {})
        if sig.get("day") != str(td): sig.clear(); sig.update(day=str(td), n=0)
        if sig["n"] >= strat.max_per_day: return
        bars = self.bars(cli, pair, td)
        if bars is None or len(bars) == 0: return
        hist = self.daily(cli, pair, td)
        orders = strat.signal(hist, bars, pair, ps["sstate"], self.now)
        for o in orders:
            sig["n"] += 1
            ps["orders"].append({"o": o2d(o), "status": "armed", "cid": f"{sid[:6]}-{pair}-{td:%Y%m%d}-s{sig['n']}", "exp": str(td),
                                 "gtd": (self.now + timedelta(minutes=o.gtd_minutes)).isoformat() if o.gtd_minutes else None})
            self.log(f"[{sid}] {pair} signal {'BUY' if o.side == 1 else 'SELL'} {o.kind} {o.meta}")

    def intraday_orders(self, sid, cli, pair, ps, ptrades, ppend, td, nav, mids, prices):
        if not ps["orders"]: return
        spr_now = None
        if pair in prices: b, a, tradeable = prices[pair]; spr_now = a - b
        spr = typ_spread(pair)
        # a fill happened -> cancel OCO siblings, remember the trade's meta
        if ptrades:
            for o in ppend: cli.cancel_order(o["id"]); self.log(f"[{sid}] {pair} OCO cancel {o['id']}")
            for r in ps["orders"]:
                if r["status"] in ("planned", "armed", "placed"): r["status"] = "cancelled"
            return
        ix = self.intraday(cli, pair, td)
        if ix is None: return
        day_open, lo, hi = ix
        pend_by_cid = {o.get("clientExtensions", {}).get("id"): o for o in ppend}
        for r in ps["orders"]:
            if r["status"] in ("filled", "cancelled", "expired", "missed"): continue
            if r["exp"] < str(td): r["status"] = "expired"; continue
            o = d2o(r["o"])
            if r["status"] == "planned" and is_armed(o, lo, hi): r["status"] = "armed"
            if r["status"] == "armed" and r.get("gtd") and datetime.fromisoformat(r["gtd"]) <= self.now:
                r["status"] = "expired"; continue
            if r["status"] == "placed" and r["cid"] not in pend_by_cid:
                r["status"] = "missed"; continue     # cancelled by OANDA (GTD / priceBound)
            if r["status"] == "placed" and o.sl_daylow:   # keep 'one tick beyond today's extreme' current
                level, sl, _, tp = entry_levels(o, pair, day_open, lo, hi, spr)
                if abs(sl - r.get("sl", sl)) >= pip(pair) * 0.5:
                    units = abs(int(float(pend_by_cid[r["cid"]]["units"])))
                    body = order_body(pair, o, units, level, sl, None, tp, day_bounds(td)[1] - timedelta(minutes=1), r["cid"] + "x", sid, spr)
                    cli.replace_order(pend_by_cid[r["cid"]]["id"], body); r["cid"] += "x"; r["sl"] = sl
                    self.log(f"[{sid}] {pair} move pre-fill stop to {fmt_px(pair, sl)}")
                continue
            if r["status"] != "armed": continue
            if getattr(self, "_margin_full", False):
                self.log(f"[{sid}] {pair} margin used above limit; defer"); continue
            if spr_now is None or not prices[pair][2] or spr_now > MAX_SPREAD_MULT * spr:
                self.log(f"[{sid}] {pair} spread {spr_now} too wide; defer"); continue
            if o.kind == "market":
                level = (prices[pair][1] if o.side == 1 else prices[pair][0])
                sl = o.sl if o.sl is not None else level - o.side * o.sl_dist
                tp = o.tp if o.tp is not None else (level + o.side * o.tp_dist if o.tp_dist else None)
                sl_dist = o.sl_dist if o.sl is None else None
            else:
                level, sl, sl_dist, tp = entry_levels(o, pair, day_open, lo, hi, spr)
            if o.kind == "limit" and (level - (prices[pair][1] if o.side == 1 else prices[pair][0])) * o.side > 0:
                self.log(f"[{sid}] {pair} limit {fmt_px(pair, level)} already through the market; skip"); r["status"] = "missed"; continue
            if (level - sl) * o.side <= 0: r["status"] = "missed"; continue
            units = units_for_risk(pair, level, sl, nav, self.cfg["risk_pct"], mids)
            if units < 1: r["status"] = "missed"; continue
            exp_day = date.fromisoformat(r["exp"])
            gtd = day_bounds(exp_day)[1] - timedelta(minutes=1)

"""Minimal OANDA v20 REST client (practice by default). Docs: https://developer.oanda.com/rest-live-v20/
Write calls are refused unless the environment is 'practice' or FX_ALLOW_LIVE=YES."""
import os, time, json
import requests
import pandas as pd

HOSTS = {"practice": "https://api-fxpractice.oanda.com", "live": "https://api-fxtrade.oanda.com"}

class OandaError(RuntimeError):
    pass

class Oanda:
    def __init__(self, token, account, env="practice", dry_run=False, min_interval=0.06):
        if env not in HOSTS: raise ValueError("env must be practice or live")
        if env == "live" and os.environ.get("FX_ALLOW_LIVE") != "YES":
            raise OandaError("live environment refused (set FX_ALLOW_LIVE=YES only with explicit approval)")
        self.base, self.account, self.env, self.dry = HOSTS[env], account, env, dry_run
        self.s = requests.Session()
        self.s.headers.update({"Authorization": f"Bearer {token}", "Content-Type": "application/json",
                               "Accept-Datetime-Format": "RFC3339"})
        self.min_interval, self._last = min_interval, 0.0
        self.writes = []   # log of write calls (and of would-be writes in dry-run)

    def _req(self, method, path, params=None, body=None):
        wait = self.min_interval - (time.time() - self._last)
        if wait > 0: time.sleep(wait)
        for attempt in range(4):
            self._last = time.time()
            r = self.s.request(method, self.base + path, params=params, data=json.dumps(body) if body is not None else None, timeout=30)
            if r.status_code == 429 or r.status_code >= 500:
                time.sleep(1.5 * (attempt + 1)); continue
            if r.status_code >= 400:
                raise OandaError(f"{method} {path} -> {r.status_code}: {r.text[:300]}")
            return r.json() if r.text else {}
        raise OandaError(f"{method} {path} failed after retries")

    def _write(self, method, path, body=None):
        self.writes.append({"method": method, "path": path, "body": body})
        if self.dry: return {"dryRun": True}
        return self._req(method, path, body=body)

    # ---- reads -----------------------------------------------------------
    def accounts(self): return self._req("GET", "/v3/accounts")["accounts"]
    def summary(self): return self._req("GET", f"/v3/accounts/{self.account}/summary")["account"]
    def instruments(self, names=None):
        p = {"instruments": ",".join(names)} if names else None
        return {i["name"]: i for i in self._req("GET", f"/v3/accounts/{self.account}/instruments", params=p)["instruments"]}
    def pricing(self, names):
        js = self._req("GET", f"/v3/accounts/{self.account}/pricing", params={"instruments": ",".join(names)})
        out = {}
        for p in js["prices"]:
            if p.get("bids") and p.get("asks"):
                out[p["instrument"]] = (float(p["bids"][0]["price"]), float(p["asks"][0]["price"]), p.get("tradeable", True))
        return out
    def candles(self, instrument, granularity="D", count=None, frm=None, price="M"):
        p = {"granularity": granularity, "price": price, "dailyAlignment": 17, "alignmentTimezone": "America/New_York"}
        if count: p["count"] = min(int(count), 5000)
        if frm: p["from"] = frm
        js = self._req("GET", f"/v3/instruments/{instrument}/candles", params=p)
        rows = []
        for c in js["candles"]:
            m = c["mid"]
            rows.append({"time": pd.Timestamp(c["time"]), "open": float(m["o"]), "high": float(m["h"]), "low": float(m["l"]),
                         "close": float(m["c"]), "volume": int(c.get("volume", 0)), "complete": c["complete"]})
        return pd.DataFrame(rows)
    def open_trades(self): return self._req("GET", f"/v3/accounts/{self.account}/openTrades")["trades"]
    def pending_orders(self): return self._req("GET", f"/v3/accounts/{self.account}/pendingOrders")["orders"]
    def trade(self, tid): return self._req("GET", f"/v3/accounts/{self.account}/trades/{tid}")["trade"]
    def closed_trades(self, count=500):
        return self._req("GET", f"/v3/accounts/{self.account}/trades", params={"state": "CLOSED", "count": count})["trades"]

    # ---- writes ----------------------------------------------------------
    def create_order(self, order): return self._write("POST", f"/v3/accounts/{self.account}/orders", {"order": order})
    def replace_order(self, oid, order): return self._write("PUT", f"/v3/accounts/{self.account}/orders/{oid}", {"order": order})
    def cancel_order(self, oid): return self._write("PUT", f"/v3/accounts/{self.account}/orders/{oid}/cancel")
    def set_stop(self, tid, price): return self._write("PUT", f"/v3/accounts/{self.account}/trades/{tid}/orders", {"stopLoss": {"price": price, "timeInForce": "GTC"}})
    def close_trade(self, tid): return self._write("PUT", f"/v3/accounts/{self.account}/trades/{tid}/close", {"units": "ALL"})

def build(rows, opens, now, systems):
    today = now.astimezone(ET).date(); wk0 = today - timedelta(days=today.weekday())
    out = [f"[PAPER] fx-experts (OANDA practice) — scorecard {now.astimezone(CT):%a %b %d %H:%M} CT"]
    for sid in systems + ["ALL"]:
        ts = [r for r in rows if sid == "ALL" or r["sid"] == sid]
        d = [t for t in ts if t["closed"].astimezone(ET).date() == today]
        wk = [t for t in ts if t["closed"].astimezone(ET).date() >= wk0]

"""fx-combo SHADOW broker (Marvin 2026-10-09): runs fx-experts systems against LIVE OANDA practice prices but keeps every
order and trade in a local virtual book. NOTHING is ever written to OANDA (all write methods are overridden and the
parent's _write raises), so the real practice account that fx-experts trades is never touched.

Why shadow: the OANDA token can reach exactly one practice account (the one fx-experts trades, US rules: FIFO, no
hedging). A second bot placing real orders on the same pairs there would net against / close fx-experts trades.
To run this combo with real practice orders, create a separate OANDA practice sub-account and point a non-shadow
runner at it (see docs/COMBO.md).

HARD exits on every trade (same rule as xp-combo):
  stop = tighter of the book stop and fill -/+ HARD_STOP_PCT (1%)
  take-profit = nearer of the book target and fill +/- HARD_TP_PCT (1%)
  trailing-stop updates (set_stop) are accepted only if they tighten.
Every run the matcher replays the M1 candles since the last check, so a stop/TP touched between runs is filled at the
level (or at the bar open if price gapped through), conservatively stop-first when one bar touches both."""
import json, os, time, itertools
from datetime import datetime, timezone, timedelta
import pandas as pd
from .oanda import Oanda, OandaError
from .instruments import spread as typ_spread, rnd, pip, SLIP_PIPS
from .sizing import quote_to_usd

HARD_STOP_PCT = float(os.environ.get("FXC_HARD_STOP_PCT", "1.0"))
HARD_TP_PCT = float(os.environ.get("FXC_HARD_TP_PCT", "1.0"))
UTC = timezone.utc

def _iso(dt): return dt.astimezone(UTC).strftime("%Y-%m-%dT%H:%M:%S.000000000Z")
def _pdt(s): return pd.Timestamp(s).tz_convert("UTC") if pd.Timestamp(s).tzinfo else pd.Timestamp(s).tz_localize("UTC")

def hard_levels(pair, side, fill, sl, tp):
    """-> (stop, tp, src) with the hard caps applied. side +1/-1."""
    hs = fill * (1 - side * HARD_STOP_PCT / 100.0); ht = fill * (1 + side * HARD_TP_PCT / 100.0)
    src = {}
    if sl is None or (sl - hs) * side < 0: sl, src["stop"] = hs, "hard"
    else: src["stop"] = "book"
    if tp is None or (tp - ht) * side > 0 or (tp - fill) * side <= 0: tp, src["tp"] = ht, "hard"
    else: src["tp"] = "book"
    return rnd(pair, sl), rnd(pair, tp), src


class ShadowOanda(Oanda):
    def __init__(self, token, account, book_path, start_nav=50000.0, now=None, log=print):
        super().__init__(token, account, "practice", dry_run=True)
        self.book_path, self.log = book_path, log
        self.now = now or datetime.now(UTC)
        self.b = json.load(open(book_path)) if os.path.exists(book_path) else {
            "start_nav": start_nav, "realized": 0.0, "next_id": 1, "orders": {}, "trades": {}, "closed": [],
            "last_match": _iso(self.now - timedelta(minutes=2))}
        self._px = None

    # ------------------------------------------------------------ never write to OANDA
    def _write(self, method, path, body=None):
        raise OandaError("shadow broker: refusing to write to OANDA")

    def save(self):
        tmp = self.book_path + ".tmp"; json.dump(self.b, open(tmp, "w"), indent=1, default=str); os.replace(tmp, self.book_path)

    def _id(self):
        i = self.b["next_id"]; self.b["next_id"] += 1; return str(i)

    # ------------------------------------------------------------ prices
    def mids(self, names=None):
        want = set(names or []) | {t["instrument"] for t in self.b["trades"].values()} | \
               {o["instrument"] for o in self.b["orders"].values()} | \
               {"EUR_USD", "GBP_USD", "AUD_USD", "NZD_USD", "USD_JPY", "USD_CAD", "USD_CHF"}
        need = sorted(want - set(self._px or {}))
        if need:
            self._px = {**(self._px or {}), **super().pricing(need)}
        return {k: (b + a) / 2 for k, (b, a, _) in self._px.items()}

    def pricing(self, names):
        out = super().pricing(names)
        self._px = {**(self._px or {}), **out}
        return out

    def _usd(self, pair, units, entry, exit_):
        m = self.mids([pair])
        return units * (exit_ - entry) * quote_to_usd(pair, m)

    # ------------------------------------------------------------ account reads (virtual)
    def unrealized(self):
        m = self.mids(); tot = 0.0
        for t in self.b["trades"].values():
            pair = t["instrument"]; u = float(t["currentUnits"]); hs = typ_spread(pair) / 2
            px = m.get(pair)
            if px is None: continue
            exit_ = px - hs if u > 0 else px + hs
            t["unrealizedPL"] = round(self._usd(pair, u, float(t["price"]), exit_), 4); tot += t["unrealizedPL"]
        return tot

    def summary(self):
        nav = self.b["start_nav"] + self.b["realized"] + self.unrealized()
        return {"NAV": f"{nav:.4f}", "marginUsed": "0", "balance": f"{self.b['start_nav'] + self.b['realized']:.4f}",
                "openTradeCount": len(self.b["trades"]), "pendingOrderCount": len(self.b["orders"])}

    def open_trades(self): return [dict(t) for t in self.b["trades"].values()]
    def pending_orders(self): return [dict(o) for o in self.b["orders"].values()]
    def trade(self, tid):
        if tid in self.b["trades"]: return dict(self.b["trades"][tid])
        for c in self.b["closed"]:
            if c["id"] == tid: return dict(c)
        raise OandaError(f"shadow: no trade {tid}")
    def closed_trades(self, count=500): return list(self.b["closed"])[-count:]

    # ------------------------------------------------------------ writes (virtual)
    def create_order(self, order):
        self.writes.append({"method": "POST", "path": "shadow/orders", "body": order})
        o = dict(order); o["id"] = self._id(); o["createTime"] = _iso(self.now); o["state"] = "PENDING"
        if o["type"] == "MARKET":
            pair = o["instrument"]; u = int(o["units"]); side = 1 if u > 0 else -1
            m = self.mids([pair])[pair]
            fill = m + side * (typ_spread(pair) / 2 + SLIP_PIPS * pip(pair))
            self._open_trade(o, fill, self.now)
            return {"orderFillTransaction": {"price": fill}}
        self.b["orders"][o["id"]] = o
        return {"orderCreateTransaction": {"id": o["id"]}}

    def replace_order(self, oid, order):
        self.cancel_order(oid); return self.create_order(order)

    def cancel_order(self, oid):
        self.writes.append({"method": "PUT", "path": f"shadow/orders/{oid}/cancel", "body": None})
        self.b["orders"].pop(str(oid), None); return {}

    def set_stop(self, tid, price):
        self.writes.append({"method": "PUT", "path": f"shadow/trades/{tid}/orders", "body": {"stopLoss": price}})
        t = self.b["trades"].get(str(tid))
        if not t: return {}
        side = 1 if float(t["currentUnits"]) > 0 else -1; new = float(price); cur = float(t["stopLossOrder"]["price"])
        if (new - cur) * side > 0:                     # tighten only (hard stop is never loosened)
            t["stopLossOrder"]["price"] = f"{new}"; self.log(f"[shadow] {t['instrument']} trade {tid} stop {cur} -> {new}")
        return {}

    def close_trade(self, tid, reason="MARKET_ORDER_TRADE_CLOSE"):
        self.writes.append({"method": "PUT", "path": f"shadow/trades/{tid}/close", "body": None})
        t = self.b["trades"].get(str(tid))
        if not t: return {}
        pair = t["instrument"]; side = 1 if float(t["currentUnits"]) > 0 else -1
        m = self.mids([pair])[pair]
        self._close(t, m - side * typ_spread(pair) / 2, self.now, reason); return {}

    # ------------------------------------------------------------ book internals
    def _open_trade(self, o, fill, when):
        pair = o["instrument"]; u = int(o["units"]); side = 1 if u > 0 else -1
        sl = tp = None
        if o.get("stopLossOnFill"):
            s = o["stopLossOnFill"]
            sl = fill - side * float(s["distance"]) if "distance" in s else float(s["price"])
        if o.get("takeProfitOnFill"): tp = float(o["takeProfitOnFill"]["price"])
        book_dist = abs(fill - sl) if sl is not None else None
        sl, tp, src = hard_levels(pair, side, fill, sl, tp)
        # size on the EFFECTIVE stop (same rule as xp-combo): the Runner sized on the book stop; when the hard 1% stop
        # is tighter, scale units up so a stop-out still risks ~risk_pct of NAV (capped at 4x).
        if src["stop"] == "hard" and book_dist:
            k = min(4.0, book_dist / max(abs(fill - sl), 1e-9))
            if k > 1.0001:
                u = int(u * k); src["size_x"] = round(k, 2)
        tid = self._id(); ce = o.get("tradeClientExtensions") or {}
        t = {"id": tid, "instrument": pair, "price": f"{rnd(pair, fill)}", "openTime": _iso(when), "initialUnits": str(u),
             "currentUnits": str(u), "state": "OPEN", "clientExtensions": ce, "stopLossOrder": {"price": f"{sl}", "state": "PENDING"},
             "takeProfitOrder": {"price": f"{tp}", "state": "PENDING"}, "hard": src, "unrealizedPL": 0.0}
        self.b["trades"][tid] = t
        self.b["orders"].pop(o.get("id"), None)
        self.log(f"[shadow] FILL {ce.get('comment')} {pair} {u}u @ {rnd(pair, fill)} | HARD SL {sl} ({src['stop']}) "
                 f"TP {tp} ({src['tp']})")
        return t

    def _close(self, t, px, when, reason):
        pair = t["instrument"]; u = float(t["currentUnits"])
        pl = self._usd(pair, u, float(t["price"]), px)
        t.update(state="CLOSED", closeTime=_iso(when), averageClosePrice=f"{rnd(pair, px)}", realizedPL=f"{pl:.4f}",
                 financing="0", closeReason=reason, currentUnits="0")
        if reason == "STOP_LOSS_ORDER": t["stopLossOrder"]["state"] = "FILLED"
        if reason == "TAKE_PROFIT_ORDER": t["takeProfitOrder"]["state"] = "FILLED"
        self.b["realized"] += pl
        self.b["trades"].pop(t["id"], None); self.b["closed"].append(t)
        self.log(f"[shadow] CLOSE {t['clientExtensions'].get('comment')} {pair} @ {rnd(pair, px)} {reason} P/L {pl:+.2f}")

    def m1(self, pair, frm):
        df = self.candles(pair, "M1", frm=_iso(frm))
        if df.empty: return df
        return df[df["complete"]].reset_index(drop=True)

    def match(self):
        """Replay completed M1 bars since the last match: fill resting stop/limit entries, then stops/targets.
        This is the software ('virtual') exit: it fires whatever happens to any broker order."""
        since = _pdt(self.b["last_match"]).to_pydatetime()
        pairs = sorted({o["instrument"] for o in self.b["orders"].values()} | {t["instrument"] for t in self.b["trades"].values()})
        ends = []
        for pair in pairs:
            try: bars = self.m1(pair, since - timedelta(minutes=1))
            except OandaError as e: self.log(f"[shadow] {pair} M1 fetch failed: {e}"); ends.append(since); continue
            last_seen = since
            hs, slip = typ_spread(pair) / 2, SLIP_PIPS * pip(pair)
            for _, b in bars.iterrows():
                bt = b["time"].to_pydatetime(); bend = bt + timedelta(minutes=1)
                if bend <= since: continue
                last_seen = max(last_seen, bend)
                # 1) exits for trades open before this bar
                for t in [t for t in list(self.b["trades"].values()) if t["instrument"] == pair and _pdt(t["openTime"]) < pd.Timestamp(bt)]:
                    side = 1 if float(t["currentUnits"]) > 0 else -1
                    sl = float(t["stopLossOrder"]["price"]); tp = float(t["takeProfitOrder"]["price"])
                    # bid side for longs' exits, ask side for shorts' (mid +/- half typical spread)
                    lo, hi, op = (b["low"] - hs, b["high"] - hs, b["open"] - hs) if side == 1 else (b["low"] + hs, b["high"] + hs, b["open"] + hs)
                    if (lo <= sl) if side == 1 else (hi >= sl):
                        px = (min(sl, op) if side == 1 else max(sl, op)) - side * slip
                        self._close(t, px, bend, "STOP_LOSS_ORDER"); continue
                    if (hi >= tp) if side == 1 else (lo <= tp):
                        px = max(tp, op) if side == 1 else min(tp, op)
                        self._close(t, px, bend, "TAKE_PROFIT_ORDER")
                # 2) resting entries
                for o in [o for o in list(self.b["orders"].values()) if o["instrument"] == pair]:
                    if _pdt(o["createTime"]) >= pd.Timestamp(bend): continue
                    if o.get("gtdTime") and pd.Timestamp(bt) >= _pdt(o["gtdTime"]):
                        self.b["orders"].pop(o["id"], None); self.log(f"[shadow] {pair} order {o['id']} expired (GTD)"); continue
                    u = int(o["units"]); side = 1 if u > 0 else -1; lvl = float(o["price"])
                    lo, hi, op = (b["low"] + hs, b["high"] + hs, b["open"] + hs) if side == 1 else (b["low"] - hs, b["high"] - hs, b["open"] - hs)
                    fill = None
                    if o["type"] == "STOP" and ((hi >= lvl) if side == 1 else (lo <= lvl)):
                        fill = (max(lvl, op) if side == 1 else min(lvl, op)) + side * slip
                        bound = o.get("priceBound")
                        if bound and (fill - float(bound)) * side > 0:
                            self.b["orders"].pop(o["id"], None); self.log(f"[shadow] {pair} stop entry {o['id']} gapped past priceBound; cancelled"); continue
                    elif o["type"] == "LIMIT" and ((lo <= lvl) if side == 1 else (hi >= lvl)):
                        fill = min(lvl, op) if side == 1 else max(lvl, op)
                    if fill is not None:
                        self._open_trade(o, fill, bend)
            ends.append(last_seen)
        # advance only to the slowest pair's last completed bar (re-scanning a bar is harmless: state only moves forward)
        self.b["last_match"] = _iso(min(ends + [self.now]) if ends else self.now - timedelta(minutes=1))

===== ./fxexp/sizing.py
"""Position sizing: units so that a stop-out loses ~risk_pct of NAV (account currency USD)."""
import math

def quote_to_usd(pair, prices):
    """Factor converting 1 unit of the pair's quote currency into USD. prices: {instr: mid}."""
    base, quote = pair.split("_")
    if quote == "USD": return 1.0
    if f"USD_{quote}" in prices: return 1.0 / prices[f"USD_{quote}"]
    if f"{quote}_USD" in prices: return prices[f"{quote}_USD"]
    raise KeyError(f"no USD conversion for {quote}")

def base_to_usd(pair, prices):
    base, quote = pair.split("_")
    if base == "USD": return 1.0
    if f"{base}_USD" in prices: return prices[f"{base}_USD"]
    if f"USD_{base}" in prices: return 1.0 / prices[f"USD_{base}"]
    return prices[pair] * quote_to_usd(pair, prices)

def units_for_risk(pair, entry, stop, nav, risk_pct, prices, margin_rate=0.02, max_margin_frac=0.25):
    dist = abs(entry - stop)
    if dist <= 0 or nav <= 0: return 0
    risk_usd = nav * risk_pct / 100.0
    u = risk_usd / (dist * quote_to_usd(pair, prices))
    # margin cap: notional_usd * margin_rate <= max_margin_frac * NAV
    cap = max_margin_frac * nav / (margin_rate * base_to_usd(pair, prices))
    return int(math.floor(min(u, cap)))

"""Helpers for intraday systems: resample completed M5 bars to completed N-minute bars."""
import pandas as pd

def resample(bars, minutes):
    """bars: completed M5 rows (UTC 'time', open/high/low/close/volume). Returns only completed
    N-minute bars (buckets aligned to UTC clock), indexed 0..n-1 with a 'time' column = bucket start."""
    if bars is None or len(bars) == 0: return pd.DataFrame(columns=["time", "open", "high", "low", "close", "volume"])
    df = bars.set_index("time")
    agg = df.resample(f"{minutes}min", label="left", closed="left").agg(
        {"open": "first", "high": "max", "low": "min", "close": "last", "volume": "sum"}).dropna(subset=["open"])
    last_end = df.index[-1] + pd.Timedelta(minutes=5)
    agg = agg[agg.index + pd.Timedelta(minutes=minutes) <= last_end]
    return agg.reset_index()

===== ./fxexp/strategies/bollinger_squeeze.py
"""John Bollinger, *Bollinger on Bollinger Bands* (McGraw-Hill 2001), ch. 16 'Method I: Volatility
Breakout'.  BOOK/SUMMARY: a Squeeze is BandWidth (20-day, 2 sd) at its lowest level in six months
(~125 sessions); 'wait for a Squeeze and go with the first breakout' - a close outside a band.
Exit: Parabolic SAR whose initial stop is 'just below the range of the breakout formation' and is
incremented each day (the book's conservative exit; a tag of the opposite band is the alternative).
DEFAULT: breakout must come within 20 sessions (one band period) of the last squeeze reading;
formation = squeeze bar..breakout bar, at least 5 bars; SAR 0.02/0.02/0.20 (Wilder);
entry at the next day's open (market).  Volume confirmation (II/AD/MFI) not used: FX has no
central volume.  No fixed take-profit in the book."""
from .base import Strategy, Order, Manage
from ..indicators import bollinger, parabolic_step
from ..instruments import pip

class BollingerSqueeze(Strategy):
    sid = "bollinger-squeeze"; expert = "John Bollinger"; style = "breakout (volatility expansion)"
    book = "Bollinger on Bollinger Bands (2001)"
    warmup = 150; LOOK = 125; WINDOW = 20
    def plan(self, hist, pair, state):
        if len(hist) < self.warmup: return []
        h = hist.iloc[-(self.LOOK + self.WINDOW + 25):]
        lo, mid, up = bollinger(h["close"]); bw = (up - lo) / mid
        sq = bw <= bw.rolling(self.LOOK).min() + 1e-15
        c = h["close"]; n = len(h)
        recent = [i for i in range(n - 1 - self.WINDOW, n - 1) if sq.iloc[i]]
        if not recent: return []
        s = recent[-1]
        outside = [(c.iloc[i] > up.iloc[i]) or (c.iloc[i] < lo.iloc[i]) for i in range(s + 1, n)]
        if not outside or not outside[-1] or any(outside[:-1]): return []   # first breakout only, on the last bar
        f0 = min(s, n - 5); t = pip(pair)
        if c.iloc[-1] > up.iloc[-1]:
            sl = float(h["low"].iloc[f0:].min()) - t
            return [Order(+1, kind="market", sl=sl, meta={"sar": sl, "ep": float(h["high"].iloc[-1]), "af": 0.02})]
        sl = float(h["high"].iloc[f0:].max()) + t
        return [Order(-1, kind="market", sl=sl, meta={"sar": sl, "ep": float(h["low"].iloc[-1]), "af": 0.02})]
    def manage(self, pos, hist, pair, state):
        m = pos.meta; hi, lo = float(hist["high"].iloc[-1]), float(hist["low"].iloc[-1])
        if "sar" not in m:  # state lost: restart the Parabolic from the current broker stop
            m.update(sar=pos.sl, ep=hi if pos.side == 1 else lo, af=0.02)
        phi, plo = float(hist["high"].iloc[-2]), float(hist["low"].iloc[-2])
        sar, ep, af = parabolic_step(m["sar"], m["ep"], m["af"], pos.side == 1, hi, lo, phi, plo)
        m.update(sar=sar, ep=ep, af=af)
        new = max(pos.sl, sar) if pos.side == 1 else min(pos.sl, sar)
        return Manage(new_sl=new)

===== ./fxexp/strategies/brooks_range.py
"""Al Brooks, *Trading Price Action Trading Ranges* (Wiley 2012).
BOOK principles (Brooks: "most breakout attempts from a trading range fail"; "buy low, sell high";
enter on a stop beyond a reversal signal bar, protective stop beyond the signal bar, scalp toward
the middle of the range with reward at least as large as risk).  Brooks trades discretionally on
5-minute charts; the numbers below are OUR mechanical translation (flagged DEFAULT):
 * Chart: 1-hour bars built from OANDA M5 candles.  Trading range = the prior 24 bars: width <= 8x the
   average bar range, 20-EMA roughly flat (moved <= 30% of the range width) and price crossed the
   20-EMA at least 4 times (two-sided trading).
 * Failed upside breakout: the last completed bar trades above the range high but closes back inside
   and is a bear bar (close < open) -> SELL STOP 1 pip below that bar's low, stop 1 pip above its
   high, take-profit at the range midpoint; skipped unless reward >= risk.  Mirror for longs.
 * Entry order valid 60 minutes (the next bar); day trade, flat before 17:00 NY."""
from .base import Strategy, Order
from ._bars import resample
from ..indicators import ema
from ..instruments import pip

class BrooksRangeFade(Strategy):
    sid = "brooks-range-fade"; expert = "Al Brooks"; style = "fade failed breakouts of trading ranges"
    book = "Trading Price Action Trading Ranges (2012)"
    warmup = 1; intraday = True; max_per_day = 2
    N = 24
    def signal(self, hist, bars, pair, state, now):
        h1 = resample(bars, 60)
        if len(h1) < self.N + 21: return []
        t = str(h1["time"].iloc[-1])
        if state.get("last_bar") == t: return []
        state["last_bar"] = t
        p = pip(pair); e = ema(h1["close"], 20)
        rg = h1.iloc[-self.N - 1:-1]; er = e.iloc[-self.N - 1:-1]
        rh, rl = float(rg["high"].max()), float(rg["low"].min()); w = rh - rl
        avgbar = float((rg["high"] - rg["low"]).mean())
        side_ = (rg["close"] - er) > 0
        crosses = int((side_ != side_.shift()).iloc[1:].sum())
        flat = abs(float(er.iloc[-1] - er.iloc[0])) <= 0.3 * w
        if not (w > 0 and w <= 8 * avgbar and flat and crosses >= 4): return []
        b = h1.iloc[-1]; mid = (rh + rl) / 2
        meta = {"range_hi": rh, "range_lo": rl, "crosses": crosses}
        if b.high > rh and b.close < rh and b.close < b.open:
            en, sl = float(b.low) - p, float(b.high) + p
            if en - mid >= sl - en > 0:
                return [Order(-1, price=en, sl=sl, tp=mid, gtd_minutes=60, close_eod=True, meta=meta)]
        if b.low < rl and b.close > rl and b.close > b.open:
            en, sl = float(b.high) + p, float(b.low) - p
            if mid - en >= en - sl > 0:
                return [Order(+1, price=en, sl=sl, tp=mid, gtd_minutes=60, close_eod=True, meta=meta)]
        return []

"""Toby Crabel, *Day Trading with Short Term Price Patterns and Opening Range Breakout* (Traders
Press, 1990).  Studied currency futures (Swiss franc, D-mark) among other markets.
BOOK/SUMMARY: volatility contraction precedes expansion; after an ID/NR4 (inside day that is also

import numpy as np
from .base import Strategy, Order

class CrabelNR4(Strategy):
    sid = "crabel-idnr4"; expert = "Toby Crabel"; style = "breakout (opening range / contraction)"

===== ./fxexp/strategies/dalton_value.py
"""James F. Dalton (with E. Jones & R. Dalton), *Mind Over Markets* (updated ed., Wiley 2013).
BOOK: value area = price region holding 70% of the day's volume, built outward from the
highest-volume price by comparing the two prices above vs the two below (Appendix 1).
Value-Area Rule (p.279-280): if the market opens outside the previous day's value area and then
trades inside it for two half-hour periods (acceptance), it is likely to trade through the entire
value area. Dalton warns the rule alone is "little better than a flip of a coin" without context.
DEFAULT / interpretation:
 * FX day = 17:00-17:00 NY; profile from the previous day's OANDA M5 candles with tick volume spread
   evenly across each candle's range, 1-pip price bins.
 * Acceptance = two consecutive completed 30-minute periods closing inside the value area, before
   12:00 NY.  Enter at market toward the far edge: take-profit = opposite value-area edge.
 * Stop = 1 pip beyond today's extreme outside value (the failed side); skip if risk > reward or
   the target is < 5 pips away.  No context filters (Dalton's caveat).  Day trade."""
import numpy as np
from datetime import timedelta
from zoneinfo import ZoneInfo
from .base import Strategy, Order
from ._bars import resample
from ..instruments import pip
NY = ZoneInfo("America/New_York")

def volume_profile(bars, p):
    """Returns (prices array, volume array) at 1-pip bins."""
    lo = int(round(float(bars["low"].min()) / p)); hi = int(round(float(bars["high"].max()) / p))
    vol = np.zeros(hi - lo + 1)
    for l, h, v in zip(bars["low"], bars["high"], bars["volume"]):
        a, b = int(round(l / p)) - lo, int(round(h / p)) - lo
        vol[a:b + 1] += (v if v > 0 else 1) / (b - a + 1)
    return (np.arange(lo, hi + 1) * p), vol

def value_area(prices, vol, frac=0.70):
    """Dalton Appendix 1: start at the POC, add the larger of the two-price sums above/below."""
    poc = int(np.argmax(vol)); lo = hi = poc; acc = vol[poc]; tot = vol.sum(); n = len(vol)
    while acc < frac * tot and (lo > 0 or hi < n - 1):
        up = vol[hi + 1:hi + 3].sum() if hi < n - 1 else -1
        dn = vol[max(lo - 2, 0):lo].sum() if lo > 0 else -1
        if up >= dn: acc += up; hi = min(hi + 2, n - 1)
        else: acc += dn; lo = max(lo - 2, 0)
    return float(prices[lo]), float(prices[hi]), float(prices[poc])

class DaltonValueArea(Strategy):
    sid = "dalton-value"; expert = "James F. Dalton"; style = "market profile: value-area rule"
    book = "Mind Over Markets (updated ed. 2013)"
    warmup = 1; intraday = True; max_per_day = 1
    def signal(self, hist, bars, pair, state, now):
        n = now.astimezone(NY); today = (n + timedelta(hours=7)).date()
        if 12 <= n.hour < 17: return []
        before = sorted(d for d in set(bars["td"]) if d < today)
        if not before: return []
        prev = bars[bars["td"] == before[-1]]; cur = bars[bars["td"] == today]
        if len(prev) < 48 or len(cur) < 6: return []
        p = pip(pair)
        val, vah, poc = value_area(*volume_profile(prev, p))
        o = float(cur["open"].iloc[0])
        m30 = resample(cur, 30)
        if len(m30) < 2: return []
        last2 = m30["close"].iloc[-2:]
        if not ((last2 >= val) & (last2 <= vah)).all(): return []
        c = float(cur["close"].iloc[-1]); meta = {"VAL": val, "VAH": vah, "POC": poc, "open": o}
        if o < val:
            sl = float(cur["low"].min()) - p; tp = vah
            if tp - c >= max(c - sl, 5 * p) and c > sl:
                return [Order(+1, kind="market", sl=sl, tp=tp, close_eod=True, meta=meta)]
        elif o > vah:
            sl = float(cur["high"].max()) + p; tp = val
            if c - tp >= max(sl - c, 5 * p) and sl > c:
                return [Order(-1, kind="market", sl=sl, tp=tp, close_eod=True, meta=meta)]
        return []

===== ./fxexp/strategies/faith_turtle.py
"""Curtis Faith, *Way of the Turtle* (McGraw-Hill 2007) / 'The Original Turtle Trading Rules'.
BOOK (System 1): enter when price exceeds the 20-day high/low by one tick; skip the signal if the
last 20-day breakout (either direction, taken or not) was a winner - a breakout counts as losing if
price moved 2N against it before a profitable 10-day exit; if skipped, still take the 55-day
'failsafe' breakout.  Stop 2N from entry.  Exit at a 10-day low (long) / 10-day high (short).
N = (19*PDN + TR)/20.
DEFAULT/deviations: one unit only (no pyramiding at 1/2 N), sized to the account risk % instead of
the Turtles' 1%-of-equity-per-N unit; 1 tick = 1 pip (historical currency-futures tick)."""
import math
from .base import Strategy, Order, Manage
from ..indicators import turtle_n
from ..instruments import pip

def _hypo_update(hist, n_series, st):
    """Incrementally simulate hypothetical System-1 trades on every 20-day breakout (daily
    resolution) to know whether the *last* breakout was a winner. st persists between calls."""
    H, L, C, O = hist["high"].to_numpy(), hist["low"].to_numpy(), hist["close"].to_numpy(), hist["open"].to_numpy()
    N = n_series.to_numpy()
    i = st.get("i", 21)
    tr = st.get("trade")
    while i < len(hist):
        if tr is None:
            h20, l20 = H[i - 20:i].max(), L[i - 20:i].min()
            if not math.isnan(N[i - 1]):
                if H[i] > h20:
                    e = max(O[i], h20); tr = {"side": 1, "entry": e, "stop": e - 2 * N[i - 1]}
                elif L[i] < l20:
                    e = min(O[i], l20); tr = {"side": -1, "entry": e, "stop": e + 2 * N[i - 1]}
                if tr is not None:  # same-day stop check (conservative)
                    if (tr["side"] == 1 and L[i] <= tr["stop"]) or (tr["side"] == -1 and H[i] >= tr["stop"]):
                        st["last_winner"] = False; tr = None
            i += 1; continue
        s = tr["side"]; l10, h10 = L[i - 10:i].min(), H[i - 10:i].max()
        if s == 1:
            if L[i] <= tr["stop"]: st["last_winner"] = False; tr = None
            elif L[i] < l10: st["last_winner"] = min(O[i], l10) > tr["entry"]; tr = None
        else:
            if H[i] >= tr["stop"]: st["last_winner"] = False; tr = None
            elif H[i] > h10: st["last_winner"] = max(O[i], h10) < tr["entry"]; tr = None
        i += 1
    st["i"], st["trade"] = i, tr
    return st.get("last_winner", False), tr is not None

class FaithTurtle(Strategy):
    sid = "faith-turtle"; expert = "Curtis Faith"; style = "breakout (trend following)"
    book = "Way of the Turtle (2007) / The Original Turtle Trading Rules"
    warmup = 60
    def plan(self, hist, pair, state):
        if len(hist) < self.warmup: return []
        if state.get("_first") != str(hist.index[0]) or state.get("_len", 0) > len(hist):
            state.clear()  # live runs pass a rolling window: recompute from scratch
        state["_first"], state["_len"] = str(hist.index[0]), len(hist)
        n = turtle_n(hist)
        last_winner, hypo_open = _hypo_update(hist, n, state.setdefault("hypo", {}))
        N = float(n.iloc[-1]); t = pip(pair)
        if not N > 0: return []
        meta = {"N": N, "last_winner": last_winner}
        if not last_winner and not hypo_open:
            hi, lo, lb = hist["high"].iloc[-20:].max(), hist["low"].iloc[-20:].min(), 20
        else:
            hi, lo, lb = hist["high"].iloc[-55:].max(), hist["low"].iloc[-55:].min(), 55
        meta["lookback"] = lb
        return [Order(+1, price=hi + t, sl_dist=2 * N, meta=dict(meta)),
                Order(-1, price=lo - t, sl_dist=2 * N, meta=dict(meta))]
    def manage(self, pos, hist, pair, state):
        t = pip(pair)
        if pos.side == 1:
            return Manage(new_sl=max(pos.sl, hist["low"].iloc[-10:].min() - t))
        return Manage(new_sl=min(pos.sl, hist["high"].iloc[-10:].max() + t))

===== ./fxexp/strategies/lien_fader.py
"""Kathy Lien, *Day Trading and Swing Trading the Currency Market* (Wiley), 'The Fader'.
BOOK rules (ch. Technical Trading Strategies; reprinted at TradeWins):
 1. 14-period ADX (daily) < 35 (ideally falling - optional, not coded).
 2. Long: price breaks below the previous day's low by >= 15 pips, then
 3. buy stop 15 pips above the previous day's high.
 4. Initial stop no more than 30 pips away (we use exactly 30).
 5. Take profit at double the risk, i.e. 60 pips.  Short is the mirror image.
DEFAULT: entry orders good for the trading day only (OANDA GFD = 17:00 NY)."""
from .base import Strategy, Order
from ..indicators import adx
from ..instruments import pip

class LienFader(Strategy):
    sid = "lien-fader"; expert = "Kathy Lien"; style = "mean reversion (false-breakout fade)"
    book = "Day Trading and Swing Trading the Currency Market (Wiley, 2nd/3rd ed.)"
    warmup = 40
    def plan(self, hist, pair, state):
        if len(hist) < self.warmup: return []
        a = adx(hist.iloc[-120:], 14).iloc[-1]
        if not (a < 35): return []
        p = pip(pair); ph, pl = hist["high"].iloc[-1], hist["low"].iloc[-1]
        return [Order(+1, price=ph + 15 * p, arm=pl - 15 * p, sl_dist=30 * p, tp_dist=60 * p, meta={"adx": round(float(a), 1)}),
                Order(-1, price=pl - 15 * p, arm=ph + 15 * p, sl_dist=30 * p, tp_dist=60 * p, meta={"adx": round(float(a), 1)})]

===== ./fxexp/strategies/lien_zeros.py
"""Kathy Lien, *Day Trading and Swing Trading the Currency Market* (Wiley; 2005 1st ed. ch. 8 p.103-108,
3rd ed. ch. 10 "Technical Trading Strategy: Fading the Double Zeros").  (Also co-taught with Boris
Schlossberg at BKForex; *Millionaire Traders* is an interview book with no codable rules.)
BOOK rules (long; short is the mirror):
 1. Pair trading well below its 20-period SMA on a 10- or 15-minute chart (we use 15-minute).
 2. Enter long several pips below the figure ("00" level), no more than 10 pips (book example: 5).
 3. Initial stop no more than 20 pips below entry (we use exactly 20).
 4. At a profit of 2x risk close half and move the stop on the rest to breakeven, then trail.
DEFAULT / interpretation (not numbers from the book):
 * "well below" = last 15-min close at least 10 pips beyond the 20-SMA; "approaching" = figure within
   3-30 pips of the last close.  Entry = resting LIMIT 5 pips beyond the figure, valid 60 minutes.
 * One ticket per signal (no half-closing on a FIFO account): take-profit at 2R = 40 pips, which is
   the book's first target; the trailed second half is not modelled.
 * JPY pairs: the figure is the whole yen (e.g. 150.00)."""
import math
from .base import Strategy, Order
from ._bars import resample
from ..instruments import pip

class LienDoubleZeros(Strategy):
    sid = "lien-zeros"; expert = "Kathy Lien (& Boris Schlossberg)"; style = "intraday fade at round numbers"
    book = "Day Trading and Swing Trading the Currency Market - 'Fading the Double Zeros'"
    warmup = 1; intraday = True; max_per_day = 3
    def signal(self, hist, bars, pair, state, now):
        m15 = resample(bars, 15)
        if len(m15) < 21: return []
        last_t = str(m15["time"].iloc[-1])
        if state.get("last_bar") == last_t: return []
        state["last_bar"] = last_t
        p = pip(pair); fig = 100 * p
        c = float(m15["close"].iloc[-1]); sma = float(m15["close"].iloc[-20:].mean())
        meta = {"sma20": round(sma, 5), "close": c}
        if c < sma - 10 * p:
            f = math.floor(c / fig + 1e-9) * fig
            if 3 * p <= c - f <= 30 * p:
                e = f - 5 * p
                return [Order(+1, kind="limit", price=e, sl=e - 20 * p, tp=e + 40 * p, gtd_minutes=60, meta={**meta, "figure": round(f, 3)})]
        elif c > sma + 10 * p:
            f = math.ceil(c / fig - 1e-9) * fig
            if 3 * p <= f - c <= 30 * p:
                e = f + 5 * p
                return [Order(-1, kind="limit", price=e, sl=e + 20 * p, tp=e - 40 * p, gtd_minutes=60, meta={**meta, "figure": round(f, 3)})]
        return []

===== ./fxexp/strategies/ponsi_trend.py
"""Ed Ponsi, *Forex Patterns and Probabilities* (Wiley 2007), ch. 9 trend strategy (daily chart).
BOOK rules (via chapter summaries: thepatternsite.com Forex review, desiretotrade.com):
 1. Trend filter: 10, 20, 50 and 200-day EMAs in order (10>20>50>200 for longs).
 2. At least 10 daily closes above the 10-day EMA (below, for shorts).
 3. Entry on a pullback to the 10-day EMA.
 4. Stop = 10-day EMA minus 1/2 of the daily ATR; trailed every daily close, never loosened.
 5. Exit part at a profit equal to the risk and move the stop to breakeven; trail the rest.
DEFAULT / interpretation:
 * Entry = LIMIT at today's 10-EMA (good for the trading day). ATR = 14-day Wilder ATR (period not
   confirmed from the book).
 * One ticket (FIFO account): no take-profit; once a daily close is >= 1R in profit the stop goes to
   breakeven (book step 5 without the partial exit), then keeps trailing at 10-EMA -/+ 0.5 ATR."""
from .base import Strategy, Order, Manage
from ..indicators import ema, atr

class PonsiTrend(Strategy):
    sid = "ponsi-trend"; expert = "Ed Ponsi"; style = "trend pullback to 10-EMA"
    book = "Forex Patterns and Probabilities (2007)"
    warmup = 220
    def _ind(self, hist):
        c = hist["close"]
        return c, ema(c, 10), ema(c, 20), ema(c, 50), ema(c, 200), atr(hist, 14)
    def plan(self, hist, pair, state):
        if len(hist) < self.warmup: return []
        c, e10, e20, e50, e200, a = self._ind(hist)
        E, A = float(e10.iloc[-1]), float(a.iloc[-1])
        if not A > 0: return []
        up = e10.iloc[-1] > e20.iloc[-1] > e50.iloc[-1] > e200.iloc[-1] and (c.iloc[-10:] > e10.iloc[-10:]).all()
        dn = e10.iloc[-1] < e20.iloc[-1] < e50.iloc[-1] < e200.iloc[-1] and (c.iloc[-10:] < e10.iloc[-10:]).all()
        m = {"ema10": E, "atr": A, "risk": 0.5 * A}
        if up: return [Order(+1, kind="limit", price=E, sl=E - 0.5 * A, meta=m)]
        if dn: return [Order(-1, kind="limit", price=E, sl=E + 0.5 * A, meta=m)]
        return []
    def manage(self, pos, hist, pair, state):
        c, e10, *_, a = self._ind(hist)
        new = float(e10.iloc[-1]) - pos.side * 0.5 * float(a.iloc[-1])
        risk = pos.meta.get("risk")
        if risk and (float(c.iloc[-1]) - pos.entry) * pos.side >= risk:
            new = max(new, pos.entry) if pos.side == 1 else min(new, pos.entry)
        if pos.sl is None: return Manage()
        return Manage(new_sl=max(pos.sl, new) if pos.side == 1 else min(pos.sl, new))

===== ./fxexp/strategies/raschke_soup.py
"""Linda Bradford Raschke & Laurence Connors, *Street Smarts* (M. Gordon Publishing, 1995), ch. 4
'Turtle Soup'.  BOOK (as reprinted by TradingMarkets/Connors Group):
 1. Today makes a new 20-day low.  2. The previous 20-day low occurred at least four sessions earlier.
 3. After the market falls below the previous 20-day low, buy stop 5-10 ticks above that prior low,
    good for today only.  4. Initial stop one tick under today's low.  Shorts are the mirror image.
 Chapter text: trail the stop as the trade becomes profitable; re-enter at the original entry
 level if stopped out on day 1 or 2.  Turtle Soup Plus One text: 'take profits within two to six
 days and trail stops'.
DEFAULT: tick = 1 pip; buffer = 5 pips (book's lower bound); trail = prior day's low/high from the
first close; time exit at the close of trading day 6; one re-entry."""
from .base import Strategy, Order, Manage
from ..instruments import pip

class RaschkeSoup(Strategy):
    sid = "raschke-soup"; expert = "Linda Raschke (with Larry Connors)"; style = "mean reversion (failed-breakout fade)"
    book = "Street Smarts: High Probability Short-Term Trading Strategies (1995)"
    warmup = 25
    MAX_DAYS = 6
    def plan(self, hist, pair, state):
        if len(hist) < self.warmup: return []
        t = pip(pair); w = hist.iloc[-20:]; n = len(hist); out = []
        lo_pos = n - 20 + int(w["low"].to_numpy().argmin()); hi_pos = n - 20 + int(w["high"].to_numpy().argmax())
        l20, h20 = float(w["low"].min()), float(w["high"].max())
        if n - lo_pos >= 4:   # today (index n) is >= 4 sessions after the prior 20-day low
            out.append(Order(+1, price=l20 + 5 * t, arm=l20 - t, sl_daylow=True, meta={"level": l20 + 5 * t}))
        if n - hi_pos >= 4:
            out.append(Order(-1, price=h20 - 5 * t, arm=h20 + t, sl_daylow=True, meta={"level": h20 - 5 * t}))
        return out
    def manage(self, pos, hist, pair, state):
        t = pip(pair); k = len(hist) - pos.entry_di   # trading days held incl. entry day
        if k >= self.MAX_DAYS: return Manage(close=True, reason="time(6d)")
        if pos.side == 1: return Manage(new_sl=max(pos.sl, hist["low"].iloc[-1] - t))
        return Manage(new_sl=min(pos.sl, hist["high"].iloc[-1] + t))
    def after_stop(self, pos, day_k, pair, state):
        if day_k > 2 or pos.meta.get("reentry") or "level" not in pos.meta: return None
        return Order(pos.side, price=pos.meta["level"], sl_daylow=True,
                     expires_days=(1 if day_k == 1 else 0), meta={"level": pos.meta["level"], "reentry": True})

===== ./fxexp/strategies/tharp_random.py
"""Van K. Tharp, *Trade Your Way to Financial Freedom* (McGraw-Hill, 1999/2007), "Trying to beat
random entry" (Tharp & Tom Basso) and the position-sizing chapter.
BOOK rules: always in the market, direction by coin flip; volatility = 10-day exponential moving
average of the average true range; trailing stop 3x volatility from the close, only moved in the
trade's favour; re-enter (new coin flip) after each exit; size so a stop-out risks 1% of equity.
DEFAULT / deviations:
 * Risk 0.5% per trade (the fx-experts account-wide setting) instead of Tharp's 1%.
 * The coin flip is a deterministic hash of pair+date (reproducible, not predictable from price).
 * Re-entry happens at the next daily run (17:15 NY) after a stop-out, not the same instant.
 * Markets: six FX crosses not traded by the other systems (EUR_GBP, EUR_CHF, AUD_JPY, CAD_JPY,
   AUD_NZD, EUR_AUD) so an always-in system does not block them on this single FIFO account.
 * No take-profit: the book's only exit is the trailing stop (kept at OANDA, ratcheted daily)."""
import hashlib
from .base import Strategy, Order, Manage
from ..indicators import tharp_vol
from ..instruments import EXTRA_PAIRS

def coin(pair, day):
    return 1 if hashlib.sha256(f"{pair}|{day}".encode()).digest()[0] % 2 == 0 else -1

class TharpRandom(Strategy):
    sid = "tharp-random"; expert = "Van K. Tharp"; style = "random entry + 3x volatility trailing stop"
    book = "Trade Your Way to Financial Freedom (2nd ed. 2007)"
    warmup = 15; pairs = EXTRA_PAIRS
    def plan(self, hist, pair, state):
        if len(hist) < self.warmup: return []
        v = float(tharp_vol(hist).iloc[-1])
        if not v > 0: return []
        side = coin(pair, str(hist.index[-1].date()))
        return [Order(side, kind="market", sl_dist=3 * v, meta={"vol": v})]
    def manage(self, pos, hist, pair, state):
        if pos.sl is None: return Manage()
        v = float(tharp_vol(hist).iloc[-1]); c = float(hist["close"].iloc[-1])
        new = c - pos.side * 3 * v
        return Manage(new_sl=max(pos.sl, new) if pos.side == 1 else min(pos.sl, new))

===== ./fxexp/strategies/williams_vbo.py
"""Larry Williams, *Long-Term Secrets to Short-Term Trading* (Wiley 1999/2011), ch. 4 "Volatility
Breakouts - The Momentum Breakthrough".
BOOK (2nd ed. p.61-62, quoted): "take today's range adding a portion of it to tomorrow's opening ...
A protective stop of $1,500, or 50 percent of the previous day's range, subtracted from our entry,
is used as our protective stop, while our exit is the Bail Out, or the first profitable opening".
DEFAULT / uncertainty:
 * The book does not fix "a portion"; we use 60% of the previous day's range, both directions
   (buy stop open+0.6R, sell stop open-0.6R; first fill cancels the other).
 * 'Open' = FX daily open at 17:00 NY. Stop = 50% of the previous day's range from entry (book).
 * Exit = bailout: close at the first daily open (17:00 NY) at which the trade shows a profit (book).
   No take-profit order - the book has none; the stop lives at OANDA."""
from .base import Strategy, Order, Manage

class WilliamsVBO(Strategy):
    sid = "williams-vbo"; expert = "Larry Williams"; style = "volatility breakout off the open"
    book = "Long-Term Secrets to Short-Term Trading (ch. 4)"
    warmup = 2; PCT = 0.6
    def plan(self, hist, pair, state):
        if len(hist) < self.warmup: return []
        r = float(hist["high"].iloc[-1] - hist["low"].iloc[-1])
        if not r > 0: return []
        m = {"prev_range": r}
        return [Order(+1, from_open=self.PCT * r, sl_dist=0.5 * r, meta=dict(m)),
                Order(-1, from_open=-self.PCT * r, sl_dist=0.5 * r, meta=dict(m))]
    def manage(self, pos, hist, pair, state):
        new_open = float(hist["close"].iloc[-1])   # FX: the 17:00 NY close is the next day's open
        if (new_open - pos.entry) * pos.side > 0:
            return Manage(close=True, reason="bailout: first profitable open")
        return Manage()

===== ./fxexp/switch.py
"""On/off switch for systems:  python -m fxexp.switch [on|off] <system-id>   (no args = show status).
Turning a system off stops new entries and its daily trailing; its open trades keep their OANDA stops."""
import json, sys
from .strategies import BY_SID
CFG = "config/config.json"

def main(argv=None, path=CFG):
    argv = sys.argv[1:] if argv is None else argv
    cfg = json.load(open(path)); on = cfg["systems"]
    if argv:
        if len(argv) != 2 or argv[0] not in ("on", "off") or argv[1] not in BY_SID:
            sys.exit(f"usage: python -m fxexp.switch on|off <{'|'.join(BY_SID)}>")
        act, sid = argv
        if act == "on" and sid not in on: on.append(sid)
        if act == "off" and sid in on: on.remove(sid)
        json.dump(cfg, open(path, "w"), indent=2)
    for sid in BY_SID: print(f"{'ON ' if sid in on else 'off'}  {sid}")
    return cfg

if __name__ == "__main__": main()

import numpy as np
import pandas as pd

def daily(rows, start="2024-01-01"):
    """rows: list of (o,h,l,c) -> daily DataFrame on business days."""
    idx = pd.bdate_range(start, periods=len(rows))
    return pd.DataFrame(rows, columns=["open", "high", "low", "close"], index=idx)

def flat_daily(n, px=1.1000, rng=0.0050, start="2024-01-01"):
    rows = [(px, px + rng / 2, px - rng / 2, px) for _ in range(n)]
    return daily(rows, start)

def h4_from_daily(d, paths=None):
    """Make 6 H4 bars per trading day starting 17:00 NY of the previous evening.
    paths: optional {date_index: [(o,h,l,c),...]} overrides."""
    out = []
    for i, (dt, r) in enumerate(d.iterrows()):
        start = (pd.Timestamp(dt.date()) - pd.Timedelta(days=1) + pd.Timedelta(hours=17)).tz_localize("America/New_York").tz_convert("UTC")
        bars = (paths or {}).get(i)
        if bars is None:
            bars = [(r.open, r.high, r.low, r.close)] + [(r.close, r.close, r.close, r.close)] * 5
        for k, (o, h, l, c) in enumerate(bars):
            out.append({"time": start + pd.Timedelta(hours=4 * k), "open": o, "high": h, "low": l, "close": c})
    return pd.DataFrame(out)

def choppy_daily(n, px=1.1000, rng=0.0050, start="2024-01-01"):
    """Range-bound oscillation (low ADX); the last bar is exactly px +- rng/2."""
    rows = []
    for i in range(n):
        off = (rng / 5) * (1 if i % 2 else -1)
        rows.append((px, px + rng / 2 + off, px - rng / 2 + off, px))
    rows[-1] = (px, px + rng / 2, px - rng / 2, px)
    return daily(rows, start)

class OneShot(Strategy):
    sid = "t"; warmup = 1
    def __init__(self, orders_on, orders): self.on, self.orders, self.done = orders_on, orders, False
    def plan(self, hist, pair, state):
        if len(hist) == self.on and not self.done:
            self.done = True; return self.orders()
        return []

def run(strat, d, paths):
    h4 = h4_from_daily(d, paths); from fxexp.data import to_daily
    return Sim(strat, "EUR_USD", h4, to_daily(h4)).run()

S = spread("EUR_USD"); SL = SLIP_PIPS * 0.0001

def test_stop_entry_then_target():
    d = flat_daily(6)
    paths = {3: [(1.1000, 1.1100, 1.0990, 1.1090)] + [(1.109, 1.109, 1.109, 1.109)] * 5}
    tr = run(OneShot(3, lambda: [Order(1, price=1.1010, sl_dist=0.0030, tp_dist=0.0060)]), d, paths)
    assert len(tr) == 1 and tr[0].reason == "target"
    assert tr[0].entry == pytest.approx(1.1010 + SL)   # ask-triggered fill at level + slippage
    assert tr[0].r == pytest.approx(0.0060 / 0.0030, rel=1e-6)

class FakeCli:
    def __init__(self, daily_df, intraday=(1.1, 1.09, 1.11), prices=None):
        self.d, self.ix = daily_df, intraday; self.trades, self.orders, self.writes = [], [], []
        self.prices = prices or {"EUR_USD": (1.09993, 1.10007, True)}
    def candles(self, pair, gran, count=None, frm=None, price="M"):
        if gran == "D":
            df = self.d.copy(); df["time"] = [pd.Timestamp(i) - pd.Timedelta(hours=7) for i in df.index]
            df["time"] = df["time"].dt.tz_localize(NY).dt.tz_convert("UTC"); df["complete"] = True
            return df.reset_index(drop=True)

        return pd.DataFrame([{"time": pd.Timestamp.now(tz="UTC"), "open": o, "high": h, "low": l, "close": o, "complete": True}])
    def pricing(self, names): return self.prices

    def open_trades(self): return self.trades
    def pending_orders(self): return self.orders
    def trade(self, tid): return {"price": "1.1", "stopLossOrder": {"state": "FILLED"}}

def m5(rows, start):
    """rows: list of (o,h,l,c[,vol]); start: aware datetime of the first bar."""
    out = []
    for k, r in enumerate(rows):
        o, h, l, c = r[:4]; v = r[4] if len(r) > 4 else 10

    df = pd.DataFrame(out); df["td"] = [trading_day(t.to_pydatetime()) for t in df["time"]]
    return df
